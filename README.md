Rashmi Warbhe - Portfolio Website

A responsive personal portfolio website for Rashmi Warbhe, a Robotics & Artificial Intelligence Engineering graduate interested in software development, web technologies, and artificial intelligence.

About the Project

This portfolio presents Rashmi's:

Professional introduction

-Technical skills

-Educational background

-Work experience

-Contact information

-LinkedIn, GitHub, and LeetCode profiles

The website includes a modern responsive layout, animated particle background, typing-effect role animation, timeline-based education and experience sections, and a contact form.

Technologies Used

-Frontend

-HTML5

-CSS3

-JavaScript


Project Structure

portfolio/
├── index.html
├── style.css
└── images/
    └── photo.jpeg

Make sure the profile image is available at ./images/photo.jpeg, because index.html references this path.

How to Run

Download or clone the project.

Keep index.html and style.css in the same folder.

Create an images folder.

Add the profile image as photo.jpeg.

Open index.html in a web browser.

No backend server is required for the current static version.
